Qwen GEO Collector - Windows Server Deployment

1. Extract qwen_geo_collector to:
   C:\qwen_geo_collector

2. Run:
   setup_server.bat

3. Wait until:
   SERVER SETUP SUCCESS

4. Run:
   run_qwen_geo_all.bat

5. On the first collection:
   - Chrome may open automatically.
   - Sign in to Qwen manually.
   - Complete any human verification manually.
   - Return to the terminal and continue.

6. If a task fails or the account is blocked/quota-limited:
   - Keep the output directory.
   - Run run_qwen_geo_all.bat again.
   - Choose Resume last unfinished collection.

Do not copy browser profiles or account passwords from another computer.
